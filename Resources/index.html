连上之后

三步走完，本机网关就能被任何 OpenAI 兼容客户端使用。

  1. 点「下一步：填模型」，复制页面上的三行配置。
  2. 在 Chatbox / Cherry Studio / WorkBuddy 里新建一个 OpenAI 兼容模型，粘贴进去。
  3. 这个窗口可以关掉，网关会在状态栏继续运行。

USB 自动连接 演示模式

用数据线把手机接到这台 Mac 并开启 USB 调试。应用每 3 秒检测一次，插入后自动完成：识别设备 → adb 建立通道 → 由手机上的 Amoo App 自己发消息并读回回复，不用手动点连接。

正在检测 USB 设备…

消息不走手机的本地网关端口（会被 Amoo 拦截），而是让 Amoo 自己发。锁屏 / 息屏也能发：应用会自动唤醒屏幕、打开 Amoo 的锁屏聊天卡片，由它发送并读回回复，不需要 PIN、不需要解锁；已解锁时走普通聊天页。全过程不用手动点手机，失败会返回明确错误，不假装成功。

仅监听 127.0.0.1。adb 路径自动探测，找不到会在上方提示。拔线后自动清理通道，重新插入会自动重连。
