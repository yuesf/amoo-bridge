# Amoo Bridge for Mac

让电脑上的聊天客户端用上手机里的 Amoo。Mac 本机跑一个 OpenAI 兼容网关，USB 连手机即可。非官方工具。

**用法**：双击 `dist/Amoo Bridge Mac.app`；手机开启 USB 调试、USB 用途切到「传输文件 / MTP」后连线；客户端填三行——

- Base URL：`http://127.0.0.1:8788/v1`
- API Key：`sk-amoo`
- 模型名：`amoo-phone`

端口被占用会自动顺延，以界面显示为准。改动源码后执行 `./build.sh` 重新构建。

**电脑文件注入**：Amoo 只有手机侧的文件能力，电脑文件由网关代读——客户端消息里出现真实存在的绝对路径（`/Users/...`、`~/...`、`E:\...` 等）或附带 file part 时，网关读出内容以内嵌文本随消息发给 Amoo，Amoo 收到的就是纯文本，不会再去手机存储里找。预算：问题 1000 字符 + 文件内容共 8000 字符，单文件 16KB、最多 3 个，超限自动截断；二进制文件和图片无法内嵌，只给提示。上限可在 `main.swift` 的 `kMax*` 常量处调整。
